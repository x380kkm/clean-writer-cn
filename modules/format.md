# 中文格式
检查中文标点, 空格, 数字, 单位, 引用, 链接和文件名时加载.

本文件规定交付给用户的目标正文格式. 默认检查模式是 `fullwidth`, 即可编辑中文句子使用全角中文标点. 用户明确要求半角 ASCII 标点时使用 `ascii` 模式, 不把默认模式的检查结果用于该任务. 第一行的 `audience:` 标签, 模块标题和本文件使用的半角 ASCII 标点只属于技能文件, 不得复制到目标正文. 文章结构根据任务决定, 不套用软件手册结构.

## 标点

- 可编辑中文句子使用全角中文标点, 整句英文使用半角英文标点.
- 全角中文标点只替换句子中的标点, 不替换产品名, 接口名, 版本号和代码标识内部的半角符号. `Compatibility/GLES3` 中的 `/` 保持原样.
- 句末点号不放在行首, 标题末尾不加点号.
- 不让整段只用逗号停顿. 连续感叹号不承载额外强度时保留一个. 只能通过原标点保持情绪, 一般强调或不确定程度时保留原标点.
- 引号, 单引号和圆括号使用配对的全角中文形式. 时间使用半角冒号.
- 冒号前的内容必须能够自然引出后文.
- 破折号只解释已有内容. 改成逗号, 括号或独立句时不得添加新关系.
- 粗体只用于需要强调的界面字段, 警告和术语定义. 粗体承担导航时改成标题. 其他粗体只有在文字能够唯一保持相同情绪, 一般强调, 评价强度和不确定程度时删除; 否则保留原标记.
- 表情符号明确表达信息或情绪时, 用文字写出相同对象和强度. 含义不能唯一确定时保留原符号, 不补写解释.

## 空格和字符

- 中文与 Latin 字符或阿拉伯数字之间留一个半角空格.
- 数字与未翻译的英文单位之间留一个半角空格.
- 代码, 命令, 路径, URL, 产品原名和整句英文保持原有字符形式.
- 阿拉伯数字, 英文字母和 Markdown 标记使用半角字符.

## 数字和单位

- 五位及以上数值使用半角千分位逗号. 四位数值在同一篇正文中使用一致格式.
- 数值范围两端都写单位或百分号, 并使用 "至" 连接.
- "增加了" 和 "降低了" 表示变化量. "增加到" 和 "降低到" 表示结果值.
- 不自行换算或舍入材料中的数值.
- "降低 N 倍" 的含义不能从词语本身唯一确定. 保留原数值和表达, 不换算, 不添加解释.
- 数字, 单位, 时间和计算结果必须与材料一致.

## 引用和链接

- 引用第三方文字或图片时保留材料已经提供的作者, 出处和原始链接. 材料未提供的信息保持未知.
- Markdown 链接使用 `[文本](URL)` 形式.
- 不修改原有 URL, 引文内容, 代码标识, 专有名称和版本号.

## 文件名

- 新建文档的文件名使用半角小写字符, 不含空格.
- 多词文件名使用连字符.
- `README` 和 `LICENSE` 保持约定的大写形式.
- 用户指定文件名或已有项目规范时使用已有名称.

## 检查

- 中文标点和英文标点没有混用.
- 中文, Latin 字符, 数字和单位之间的空格正确.
- 数值范围, 变化量和结果值写法明确.
- 引文, 链接, 代码, 专有名称和版本号没有改变.
- 格式修改只作用于可编辑正文.
